# Announcer-Peringatan-Berbasis-Sensor-PIR-dan-Raspberry-PI3-
Sistem announcer otomatis berbasis Raspberry Pi 3 &amp; sensor PIR di Bandara Halim untuk memandu penumpang disabilitas &amp; lansia ke pintu khusus. Memiliki backend Python &amp; frontend HTML untuk konfigurasi jadwal aktif, unggah file audio, penyimpanan log deteksi, serta antarmuka desktop lokal/VNC.
